This folder is empty on purpose.

Drop screenshots in here with these EXACT filenames — nothing else needs
to change. Each placeholder box on the site checks for its file; if found,
the image appears and the "what to capture" instructions hide themselves.
If not found, the instructions just stay visible. Either way, nothing breaks.

1. friday-main-gui.jpg
   The Electron interface running live (idle or active state).

2. friday-agent-routing.jpg
   A debug/log view showing the AgentManager routing a command to a
   specific agent.

3. friday-n8n-workflow.jpg
   A real n8n workflow canvas used by FRIDAY.

4. friday-docker-setup.jpg
   Terminal output or a docker-compose file showing FRIDAY's containers
   running.

5. architecture-diagram.jpg
   Optional — only add this once you have a polished, hand-produced
   diagram. Until then the auto-generated component grid above it on
   the page stands in.

RECOMMENDED SIZE / FORMAT
- 1600–2000px wide is plenty (these display at full content-width,
  roughly 1100px max on desktop — anything wider is wasted file size).
- .jpg at ~80% quality for screenshots with lots of UI detail/text
  (smaller file size than PNG for this kind of image).
  Use .png only if a screenshot has transparency or very fine text you
  don't want JPEG compression artifacts on.
- Keep each file under ~500KB if you can — compress with Squoosh
  (squoosh.app, free, drag-and-drop, no install) if your screen
  recorder/tool exports larger than that.
- 16:9 or 16:10 crops read most naturally in the layout, but any
  reasonable aspect ratio will work — the image scales to full width
  and keeps its native aspect ratio.
- File extension must match exactly: .jpg (not .jpeg or .JPG) for all
  five, since that's what index.html requests.
